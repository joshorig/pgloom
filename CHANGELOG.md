# Changelog

All notable changes to this project are documented here.

The format is based on Keep a Changelog, and this project uses SemVer while it
is published as a `0.x` package.

## [0.2.0] - 2026-05-02

### Added

- Bounded subprocess runner with timeout and termination escalation.
- CLI-backed model provider that records model usage.
- Postgres-backed memory store with full-text search.
- Pluggable dashboard snapshot collectors.
- Data-backed blocker registry.
- Multiplex notification sink.

## [0.1.0] - 2026-05-02

### Added

- Initial release, renamed from orchestrator-core before public publication.
